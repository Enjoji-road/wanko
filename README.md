# 謎解きわんこそば

**ひらめいたら、もう一杯。** 90秒で小謎を何杯解けるか挑戦する、１ページ完結のHTMLゲームです。

現在は**４択・ドボン式**です。18問の小謎をシャッフル出題し、正解なら即おかわり、誤答ならその場で終了。パス、蓋を閉めて終了、自己ベスト、X共有、まだ一杯を持ったお給仕さんも用意しています。隠し謎は入口の演出だけです。

**[制作アカウント用の試遊版](https://wanko-nazotoki-prototype.mnyfumi.chatgpt.site)**（所有者のChatGPTログインが必要）。GitHub Pagesは有効化待ちです。

## 遊ぶ・公開する

`dist/index.html` をブラウザで開くと遊べます。外部依存やビルドは不要です。ローカルファイルで保存が制限されるブラウザでは、HTTPサーバーで `dist` を公開してください。

GitHub Pagesでは `dist` の内容を公開します。まだ公開URLが確認できていない間はX共有を無効にして、その理由を表示します。公開後、`dist/config.js` の `publicUrl` に確認済みURLを設定すると、公式投稿インテントから杯数とURLを共有できます。投稿の確定は本人が行います。

このリポジトリはルートから `dist/` へ移動する入口も用意しています。GitHubの **Settings → Pages → Deploy from a branch → main / (root) → Save** で公開できます。この管理設定は、GitHubへサインインした所有者が行ってください。

## 調整する

| ファイル | 変更できること |
| --- | --- |
| `dist/config.js` | 制限秒数、シャッフル方式、演出時間、掛け声、蓋の確認時間、X投稿文・URL |
| `dist/questions.js` | 小謎と４つの選択肢 `choices`。追加・削除で出題数が変わる。HTMLの修正は不要 |
| `dist/puzzle-view.js` | 出題形式の描画。新しい形式を増やす場合だけ追加 |
| `dist/model.js` | 正誤判定、出題キュー、タイマー状態、記録の検査 |
| `dist/app.js` / `style.css` / `choices.css` | UI、画面遷移、お給仕さん・お椀の演出。４択の画面配置は `choices.css` |
| `dist/extra-bowl.js` | 将来の隠し謎の独立した入口。通常の点数・保存は変更しない |

`balanced` は、易・標準・ひとひねりの３分類から各１問ずつ選んだ３問ブロックを、ブロック内も含めてシャッフルします。`random` は全体のFisher–Yatesシャッフルです。全18問を出すまでは同じ問題を繰り返さず、全問後は並べ直します。巡の境界でも直前の問題は続きません。

## 記録と４択操作

４択版の自己ベストは `wanko-choice-suddendeath-records-v1` に秒数別で保存します。入力式の `wanko-local-records-v1` は変更・削除しません。条件が異なるため記録は合算しません。リロードで進行中の制限時間は引き継がず、スタート画面に戻ります。

キーボードを出す入力欄はありません。４択をタップするか、PCでは1〜4の数字キー、Tab・Enter・Spaceで選びます。問題順に加えて選択肢の位置も毎回シャッフルします。誤答では追加加点せず、即座に「ドボン」の結果画面へ。それまでの完食数は記録します。パスには追加ペナルティを設けません。

選択時にも期限を検査するので、時間切れ後は加点できません。別タブや遊び方の表示中も時間は進みます。古い問題のボタン再発火・キー長押しの繰り返し・ダブルクリックによる意図しない次問への回答を防ぎます。正解演出のための操作待ち時間は追加していません。

問題枠を画面の残り高さへ無理に縮める処理をやめ、文字と図に必要な高さを保持します。特に低い画面や文字拡大時にはスクロールできます。時計は上部に残ります。小さい画面では装飾の一部を省き、問題と選択肢を優先します。

蓋は2.8秒以内に２回押すと終了。最初の１回では終了せず、ボタン内の案内が変わります。実際に蓋が閉じてから結果を表示します。動きを減らす設定では動きを省きます。

## 検証と作問資料

```sh
node tests/verify.cjs
```

[正解・解法と成立性の検討（ネタバレ）](docs/PUZZLES_SPOILERS.md)と、`tests/model-verification.json` を参照してください。18問×４択の全72選択について、正解が一つだけで誤答なら即終了することを検証します。４択化で解き味が変わるため、初見の面白さ・難度は試遊で継続調整する段階です。

`tests/browser-verification.json` は４択版の実ブラウザ確認結果です。スマートフォンサイズのiframeで、図を描く子要素まで問題枠に収まり、問題文と選択肢に重ならないことを確認します。実機Safariでの確認は継続課題です。

`tests/browser-fixture.html` を開発時だけ `dist/qa.html` にコピーすると、画面サイズ切替・保存破損・時計の前送り・古いボタン・長押しを確認できます。「動きを減らす」は読み込み前に設定を模擬します。`qa.html` は公開対象に含めません。OSの実際の設定切替とは区別してください。

イラスト・UIはこの試作用のSVG/CSS。外部フォント、BGM、サーバー、データベースは使用しません。既存作品『魔法学校』のコード・リポジトリ・保存データには触れていません。
